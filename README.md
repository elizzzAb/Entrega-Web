
# Pasos para la ejecución del proyecto
## Requisitos

- Java 11 o superior
- Maven 3.8.x o superior
- Visual Studio Code
- Extensiones de Visual Studio Code:
  - Extension Pack for Java
  - Spring Boot Extension Pack

## Instalación y Ejecución


###### 1. Clona el repositorio:

##### git clone https://github.com/elizzzAb/Entrega-Web.git


###### 2. Entra en la carpeta del proyecto:
cd nombre_tu_proyecto


###### 3. Abre Visual Studio Code.


###### 4. Asegúrate de tener instaladas las extensiones requeridas:
- Extension Pack for Java
- Spring Boot Extension Pack


###### 5. Haz clic en el botón "Spring Boot Dashboard" que aparece en la barra lateral de herramientas:


![1](https://github.com/user-attachments/assets/fb4702a4-bc6f-4b11-b982-1e7639ae8210)


###### 6. Busca el proyecto y haz clic en el botón "Play":

![2](https://github.com/user-attachments/assets/586a7711-27d4-45b1-9925-8da11c96069e)


###### 7. Accede al programa ingresando en el navegador la siguiente dirección:
> http://localhost:8080/vista

###### O ingresando desde vs code danto click en el simbolo de mundo:

![3](https://github.com/user-attachments/assets/793b6e14-3260-4898-a021-c012e366f46a)


> Y, luego de la ruta escribir la palabra "vista":

![image](https://github.com/user-attachments/assets/8039287b-460c-435f-bb01-d2a0771b6a6e)


> NOTA: El programa debe de estarse ejecutando de lo contrario aparecería un error.


###### 8. Si el programa no contiene errores, se visualizará lo siguiente:
